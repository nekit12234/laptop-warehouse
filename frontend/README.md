# 📦 Склад ноутбуков

Информационная система учёта ноутбуков на складе с авторизацией, ролями,
операциями прихода/расхода, отслеживанием доставки и аналитическим дашбордом.

Дипломный проект по направлению «Разработка программного обеспечения».

---

## 📖 Описание

Веб-приложение автоматизирует учёт ноутбуков на складе: позволяет вести
каталог товаров, фиксировать приход и расход, отслеживать статус доставки
покупателю и получать аналитику по остаткам в реальном времени.

Система заменяет ручной учёт в Excel и снижает вероятность ошибок
при вводе данных.

---

## ✨ Возможности

- 🔐 **Авторизация** с тремя ролями: администратор, менеджер, наблюдатель
- 📦 **Учёт ноутбуков** — добавление, редактирование, архивация, поиск
- 🚚 **Учёт поставщиков**
- 📥 **Операции склада** — приход, расход, списание
- 📦 **Массовые операции** — приход/расход сразу по нескольким моделям
- ✅ **Отслеживание доставки** — статус «В пути» / «Доставлено»
- 📜 **История операций** с указанием пользователя, даты и количества
- 📊 **Дашборд** с ключевыми показателями и графиком по брендам
- ⚠️ **Контроль низкого остатка** — подсветка позиций ниже минимума

## 🚀 Установка и запуск

### Требования

- **Python** 3.12 или новее
- **Node.js** 18 или новее
- **npm**

### 1. Клонирование

```bash
git clone <ссылка-на-репозиторий>
cd laptop-warehouse
```

Если репозитория нет — просто перейди в папку проекта.

### 2. Backend

```bash
cd backend

# Виртуальное окружение
python -m venv venv
venv\Scripts\Activate.ps1        # Windows (PowerShell)
# source venv/bin/activate       # macOS / Linux

# Зависимости
pip install -r requirements.txt

# Демо-данные (создаст warehouse.db)
python -m app.seed

# Запуск сервера
uvicorn app.main:app --reload --reload-dir app
```

Backend доступен на **http://localhost:8000**
Документация (Swagger): **http://localhost:8000/docs**

### 3. Frontend

Открой **второй терминал** (backend оставь работать):

```bash
cd frontend
npm install
npm start
```

Frontend доступен на **http://localhost:3000**

## 🔌 Основные эндпоинты API

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/api/auth/login` | Вход, получение JWT |
| `POST` | `/api/auth/register` | Регистрация |
| `GET` | `/api/laptops` | Список ноутбуков |
| `POST` | `/api/laptops` | Добавить ноутбук |
| `PUT` | `/api/laptops/{id}` | Редактировать |
| `DELETE` | `/api/laptops/{id}` | Архивировать |
| `GET` | `/api/suppliers` | Список поставщиков |
| `POST` | `/api/suppliers` | Добавить поставщика |
| `POST` | `/api/operations` | Создать операцию |
| `GET` | `/api/operations` | История операций |
| `PATCH` | `/api/operations/{id}/delivered` | Отметить доставку |
| `GET` | `/api/dashboard` | KPI для дашборда |

Полная документация — в Swagger: **http://localhost:8000/docs**

## 📋 Сценарии использования

1. **Приход товара**
   Склад → `+ Приход` → ввести количество → остаток растёт.

2. **Массовый приход от поставщика**
   Склад → `📦 Массовая операция` → выбрать тип «Приход» → добавить строки
   → применить.

3. **Продажа и отслеживание доставки**
   `− Расход` → История → `⏳ В пути` → `Отметить доставленным` → `✔ Доставлено`.

4. **Аналитика**
   Дашборд → KPI-карточки, график по брендам, список низких остатков.
